RFC / issue index

A chronological ledger of the numbered issues and RFCs that shaped SipLLM, reconstructed from git history (git log, 35 commits, tags v0.1.0 → v0.1.1 → v0.4.0). Each row is a landed change; every entry below is Implemented (present in main). Two carry formal design-doc ids referenced elsewhere in the codebase — RFC-003 (KV grow-on-demand, #35) and RFC-007 (single-pass prefill, #36).

What this index is (and is not)

This is a record of shipped work, grounded one-to-one in commits. The project uses the standard lifecycle framework — accepted → implemented, with rejected and superseded reserved for proposals that do not land. No rejected or superseded entries are listed here because none are sourced in the current history; this ledger will not invent them.

Reading the ledger

Three arcs run through the numbers, and they map to the project's phases:

Correctness & breadth (#17–#31)

Architecture dispatch (#17) unlocked nine model families — Mistral, Qwen2/2.5, Gemma 2/3, Phi-2/3, GPT-2, Mixtral/MoE — plus llama3 RoPE (#18) and sampler features (#19). The engine learned to read many models before it learned to run them lean.

Hardening & measurement (#20, #32–#34)

The SIGSEGV fix (#32) eliminated the uninitialized-read class at source; the bench harness (#33) and macOS RSS (#34) made "measured, not guessed" real by giving every claim a cross-runtime peak-RSS number.

Bounded memory (#35–#37, #46–#47)

KV grow-on-demand (#35 / RFC-003), single-pass prefill (#36 / RFC-007), the --ram-budget dial (#37), K-quant NEON (#46), and the streamed LM head (#47) are the streaming-thesis wave — each a measured peak-RSS or throughput win.

Cross-references
